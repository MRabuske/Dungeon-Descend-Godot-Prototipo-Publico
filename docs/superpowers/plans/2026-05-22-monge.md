- [ ] **Step 1: Ler `battle/battle_scene.gd` e localizar o branch END_TURN em `_execute_current_item()`**

O bloco atual se parece com:

```gdscript
			ActionData.Type.END_TURN:
				if item is AcaoDefender:
					_state.apply_defender_action(_state.get_active_player_index())
				elif item is AcaoEsperar:
					var pidx: int = _state.get_active_player_index()
					if pidx >= 0 and BattleState.PLAYERS[pidx]["class"] == "Rogue":
						_state.apply_furtivo_status(pidx)

						var p: Dictionary = BattleState.PLAYERS[pidx]
						p["hp"] = mini(p["hp"] + 15, p["max_hp"])
						_state._log("%s usa Segundo Vento! +15 HP" % BattleState.PLAYERS[pidx]["name"], "status")
				elif item is SkillSmite:
					var pidx: int = _state.get_active_player_index()
					if pidx >= 0:
						var p: Dictionary = BattleState.PLAYERS[pidx]
						if p["mp"] >= item.mp_cost:
							p["mp"] -= item.mp_cost
							_state.apply_smite_status(pidx)
						else:
							_state._log("MP insuficiente para Smite!", "status")
				_state.advance_turn()
				_after_advance()
```

- [ ] **Step 2: Adicionar SkillFlurry e SkillPassoVento com early return**

**CRÍTICO:** SkillFlurry e SkillPassoVento NÃO devem chamar `advance_turn()`. O turno continua ativo. A técnica é: colocar os handlers dessas skills ANTES do `if item is AcaoDefender:`, com `return` explícito ao final de cada bloco.

Substituir o bloco END_TURN inteiro por:

```gdscript
			ActionData.Type.END_TURN:
				if item is SkillFlurry:
					var pidx: int = _state.get_active_player_index()
					if pidx >= 0:
						var p: Dictionary = BattleState.PLAYERS[pidx]
						if p["mp"] >= item.mp_cost:
							p["mp"] -= item.mp_cost
							_state.fury_extra_attack = true
							_state._log("Monge usa Flurry of Blows!", "status")
						else:
							_state._log("Ki insuficiente!", "status")
					_refresh_ui()
					return
				elif item is SkillPassoVento:
					var pidx: int = _state.get_active_player_index()
					if pidx >= 0:
						var p: Dictionary = BattleState.PLAYERS[pidx]
						if p["mp"] >= item.mp_cost:
							p["mp"] -= item.mp_cost
							_state.has_moved = false
							_state._log("Monge usa Passo do Vento!", "status")
						else:
							_state._log("Ki insuficiente!", "status")
					_refresh_ui()
					return
				elif item is AcaoDefender:
					_state.apply_defender_action(_state.get_active_player_index())
				elif item is AcaoEsperar:
					var pidx: int = _state.get_active_player_index()
					if pidx >= 0 and BattleState.PLAYERS[pidx]["class"] == "Rogue":
						_state.apply_furtivo_status(pidx)
				elif item is SkillSegundoVento:
					var pidx: int = _state.get_active_player_index()
					if pidx >= 0 and item.pp > 0:
						item.pp -= 1
						var p: Dictionary = BattleState.PLAYERS[pidx]
						p["hp"] = mini(p["hp"] + 15, p["max_hp"])
						_state._log("%s usa Segundo Vento! +15 HP" % BattleState.PLAYERS[pidx]["name"], "status")
				elif item is SkillSmite:
					var pidx: int = _state.get_active_player_index()
					if pidx >= 0:
						var p: Dictionary = BattleState.PLAYERS[pidx]
						if p["mp"] >= item.mp_cost:
							p["mp"] -= item.mp_cost
							_state.apply_smite_status(pidx)
						else:
							_state._log("MP insuficiente para Smite!", "status")
				_state.advance_turn()
				_after_advance()
```

**Por que early return funciona:** `return` em GDScript 4 dentro de um bloco `match` sai da função inteira, sem chamar `_state.advance_turn()` e `_after_advance()`. O turno continua ativo com o jogador podendo fazer outras ações.

- `if item is SkillFlurry:` vem ANTES de `elif item is AcaoDefender:` → processado corretamente ✅
- `_refresh_ui()` + `return` → sai da função sem chamar `advance_turn()` ✅
- `fury_extra_attack = true` → habilita ataque bônus pelo mecanismo existente ✅
- `has_moved = false` → permite segundo movimento ✅
- `_state.advance_turn()` e `_after_advance()` ficam APÓS o elif chain → só chamados para os outros itens ✅
