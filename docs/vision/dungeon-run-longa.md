# Visão: Run Longa (Futuro)

Estrutura planejada para o formato completo do jogo:

## Estrutura
- **3 Atos**, cada ato com **4 andares** de salas
- **Mini-boss** ao final de cada Ato (Ato 1, Ato 2)
- **Boss final** ao final do Ato 3
- Total estimado: ~12 andares + 3 bosses, ~45-55 nós

## Referência
Inspirado em Slay the Spire — mapa visual em grafo com progressão linear por andares,
múltiplos caminhos por andar, tipos de sala variados.

## Tipos de sala planejados
- Batalha Normal
- Batalha Elite
- Boss / Mini-boss
- Evento (loot, descanso, loja)
- Mistério ("?")
